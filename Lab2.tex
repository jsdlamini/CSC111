\section*{Python String Exercises (Week 2)}

For this week, we will focus on string operations and manipulation (refer to pages 20-22 of the lecture notes).  
Emphasis should be placed on:
\begin{itemize}
    \item Using \textbf{meaningful variable names} for strings.
    \item Understanding \textbf{string indexing and slicing}.
    \item Applying various \textbf{string methods} for manipulation.
    \item Using \textbf{formatted strings} for clean output.
\end{itemize}
