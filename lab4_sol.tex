\section*{Student Marks Analysis Project (Week 4)}

This week, you will work on a practical project that involves reading data from a file, storing it in a structured format (list of dictionaries), and performing statistical analysis. This exercise will help you practice:

\begin{itemize}
    \item \textbf{File handling} - reading data from text files
    \item \textbf{Data structures} - using lists and dictionaries
    \item \textbf{Looping and iteration} - processing multiple data records
    \item \textbf{Basic statistics} - calculating averages, finding maximum/minimum
    \item \textbf{Conditional logic} - filtering and categorizing data
\end{itemize}

\subsection*{Problem Statement}

You are given a file called \texttt{marks.txt} that contains student marks data. Each line in the file has the following format:

\begin{verbatim}
student_id first_name last_name course_code mark
\end{verbatim}

Example content of \texttt{marks.txt}:
\begin{verbatim}
1 John Doe CSC101 85
2 Jane Smith MAT101 92
3 Bob Johnson CSC101 78
4 Alice Brown MAT101 88
5 Charlie Wilson CSC101 91
6 Diana Lee MAT101 85
7 Evan Davis CSC101 74
8 Fiona Clark MAT101 95
\end{verbatim}

\subsection*{Your Tasks}

\subsubsection*{Part 1: Reading and Storing Data (40 marks)}

Write a Python program that:

\begin{enumerate}
    \item Reads the data from \texttt{marks.txt} file
    \item Stores each student's data as a dictionary with the following keys:
    \begin{itemize}
        \item \texttt{student\_id} (as integer)
        \item \texttt{first\_name} (as string)
        \item \texttt{last\_name} (as string)
        \item \texttt{course\_code} (as string)
        \item \texttt{mark} (as integer)
    \end{itemize}
    \item Stores all student dictionaries in a list
    \item Displays the loaded data in a nicely formatted table
\end{enumerate}

\subsubsection*{Part 2: Data Analysis (60 marks)}

Extend your program to perform the following analyses:

\begin{enumerate}
    \item Calculate and display the average mark for all students
    \item Find and display the highest mark and the student who achieved it
    \item Find and display the lowest mark and the student who achieved it
    \item Count and display how many students passed (mark $\geq$ 50) and failed (mark $<$ 50)
    \item Calculate the average mark for each course separately
    \item Create a list of students who scored above 85 (distinction)
    \item Count how many students are in each course
\end{enumerate}

\subsection*{Requirements}

Your program must demonstrate:

\begin{itemize}
    \item Proper file handling with error checking
    \item Use of appropriate data structures (lists and dictionaries)
    \item Proper use of loops (for/while) for iteration
    \item Use of conditional statements (if/elif/else)
    \item Clear and organized output formatting
    \item Meaningful variable names and comments
\end{itemize}

\subsection*{Sample Solution Structure}

\begin{lstlisting}
# ============================================
# Student Marks Analysis Program
# CSC111 - Week 4 Practical
# ============================================

def read_student_data(filename):
    """
    Read student data from a file and return a list of dictionaries.
    Each dictionary represents one student's record.
    """
    students = []  # This will store our list of student dictionaries
    
    try:
        with open(filename, 'r') as file:
            for line in file:
                # Remove any extra whitespace and split the line
                parts = line.strip().split()
                
                # Skip empty lines
                if not parts:
                    continue
                
                # Create a dictionary for this student
                student = {
                    'student_id': int(parts[0]),
                    'first_name': parts[1],
                    'last_name': parts[2],
                    'course_code': parts[3],
                    'mark': int(parts[4])
                }
                
                # Add the student dictionary to our list
                students.append(student)
        
        print(f"Successfully loaded {len(students)} student records.")
        return students
        
    except FileNotFoundError:
        print(f"Error: The file '{filename}' was not found.")
        return []
    except Exception as e:
        print(f"Error reading file: {e}")
        return []

def display_students(students):
    """Display all student records in a formatted table."""
    print("\n" + "="*60)
    print("STUDENT RECORDS")
    print("="*60)
    print(f"{'ID':<5} {'Name':<20} {'Course':<10} {'Mark':<5}")
    print("-"*60)
    
    for student in students:
        full_name = f"{student['first_name']} {student['last_name']}"
        print(f"{student['student_id']:<5} {full_name:<20} "
              f"{student['course_code']:<10} {student['mark']:<5}")

def calculate_average(students):
    """Calculate and return the average mark of all students."""
    if not students:
        return 0
    
    total = 0
    for student in students:
        total += student['mark']
    
    return total / len(students)

def find_highest_mark(students):
    """Find and return the student with the highest mark."""
    if not students:
        return None
    
    highest = students[0]  # Start with first student
    for student in students:
        if student['mark'] > highest['mark']:
            highest = student
    
    return highest

def find_lowest_mark(students):
    """Find and return the student with the lowest mark."""
    if not students:
        return None
    
    lowest = students[0]  # Start with first student
    for student in students:
        if student['mark'] < lowest['mark']:
            lowest = student
    
    return lowest

def count_pass_fail(students):
    """Count how many students passed and failed."""
    pass_count = 0
    fail_count = 0
    
    for student in students:
        if student['mark'] >= 50:
            pass_count += 1
        else:
            fail_count += 1
    
    return pass_count, fail_count

def course_statistics(students):
    """Calculate statistics for each course."""
    course_data = {}
    
    for student in students:
        course = student['course_code']
        mark = student['mark']
        
        if course not in course_data:
            # Initialize data for this course
            course_data[course] = {
                'total': 0,
                'count': 0,
                'students': []
            }
        
        # Update course statistics
        course_data[course]['total'] += mark
        course_data[course]['count'] += 1
        course_data[course]['students'].append(student)
    
    return course_data

def find_distinction_students(students):
    """Return list of students with marks 85 or above."""
    distinction = []
    for student in students:
        if student['mark'] >= 85:
            distinction.append(student)
    
    return distinction

def main():
    print("STUDENT MARKS ANALYSIS PROGRAM")
    print("="*40)
    
    # Part 1: Read and store data
    filename = "marks.txt"
    students = read_student_data(filename)
    
    if not students:
        print("No student data to analyze. Exiting program.")
        return
    
    # Display all students
    display_students(students)
    
    # Part 2: Perform analysis
    print("\n" + "="*60)
    print("DATA ANALYSIS RESULTS")
    print("="*60)
    
    # 1. Average mark
    average = calculate_average(students)
    print(f"\n1. Average mark of all students: {average:.2f}")
    
    # 2. Highest mark
    highest = find_highest_mark(students)
    if highest:
        print(f"\n2. Highest mark: {highest['mark']}")
        print(f"   Achieved by: {highest['first_name']} {highest['last_name']} "
              f"(ID: {highest['student_id']})")
    
    # 3. Lowest mark
    lowest = find_lowest_mark(students)
    if lowest:
        print(f"\n3. Lowest mark: {lowest['mark']}")
        print(f"   Achieved by: {lowest['first_name']} {lowest['last_name']} "
              f"(ID: {lowest['student_id']})")
    
    # 4. Pass/Fail count
    pass_count, fail_count = count_pass_fail(students)
    print(f"\n4. Pass/Fail Statistics:")
    print(f"   Students passed (≥50): {pass_count}")
    print(f"   Students failed (<50): {fail_count}")
    
    # 5. Course-wise statistics
    print(f"\n5. Course-wise Statistics:")
    course_data = course_statistics(students)
    
    for course, data in course_data.items():
        if data['count'] > 0:
            course_avg = data['total'] / data['count']
            print(f"   {course}: {data['count']} students, "
                  f"Average: {course_avg:.2f}")
    
    # 6. Distinction students
    distinction = find_distinction_students(students)
    print(f"\n6. Students with Distinction (≥85): {len(distinction)}")
    for student in distinction:
        print(f"   - {student['first_name']} {student['last_name']}: "
              f"{student['mark']}")
    
    # 7. Student count per course
    print(f"\n7. Student Count per Course:")
    for course, data in course_data.items():
        print(f"   {course}: {data['count']} students")

if __name__ == "__main__":
    main()
\end{lstlisting}
