\section*{Python Exercises (Week 1) }

For this week, we will only cover up to type casting (refer to page 18 of the lecture notes).  
Emphasis should be placed on:
\begin{itemize}
    \item Using \textbf{meaningful variable names}.
    \item Ensuring students \textbf{include units} in their results.
    \item Displaying outputs with \textbf{formatted strings}, including both the input dimensions and computed metrics (area, volume, etc.).
\end{itemize}

\subsection*{Exercises}

\begin{enumerate}
    \item \textbf{Area of a Triangle}  
    
    Given a triangle with base and height, students should be able to:
    \begin{enumerate}
        \item Compute the area using the formula:
        \[
            \text{area} = 0.5 \times \text{base} \times \text{height}
        \]
        \item Display the area using a formatted string.
    \end{enumerate}

    Given dimensions \emph{length}, \emph{width}, and \emph{height}, students should:
    \begin{enumerate} 
        \item Compute the total surface area (TSA):
        \[
            \text{TSA} = 2lw + 2wh + 2lh
        \]
        \item Compute the volume:
        \[
            \text{Volume} = l \times w \times h
        \]
        \item Display both the TSA and volume using formatted strings.
