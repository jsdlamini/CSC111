\section*{Student Marks Analysis Project (Week 4)}

This week, you will work on a practical project that involves reading data from a file, storing it in a structured format (list of dictionaries), and performing statistical analysis. This exercise will help you practice:

\begin{itemize}
    \item \textbf{File handling} - reading data from text files
    \item \textbf{Data structures} - using lists and dictionaries
    \item \textbf{Looping and iteration} - processing multiple data records
    \item \textbf{Basic statistics} - calculating averages, finding maximum/minimum
    \item \textbf{Conditional logic} - filtering and categorizing data
\end{itemize}

\subsection*{Problem Statement}

You are given a file called \texttt{marks.txt} that contains student marks data. Each line in the file has the following format:

\begin{verbatim}
student_id first_name last_name course_code mark
\end{verbatim}

Example content of \texttt{marks.txt}:
\begin{verbatim}
1 John Doe CSC101 85
2 Jane Smith MAT101 92
3 Bob Johnson CSC101 78
4 Alice Brown MAT101 88
5 Charlie Wilson CSC101 91
6 Diana Lee MAT101 85
7 Evan Davis CSC101 74
8 Fiona Clark MAT101 95
\end{verbatim}

\subsection*{Your Tasks}

\subsubsection*{Part 1: Reading and Storing Data (40 marks)}

Write a Python program that:

\begin{enumerate}
    \item Reads the data from \texttt{marks.txt} file
    \item Stores each student's data as a dictionary with the following keys:
    \begin{itemize}
        \item \texttt{student\_id} (as integer)
        \item \texttt{first\_name} (as string)
        \item \texttt{last\_name} (as string)
        \item \texttt{course\_code} (as string)
        \item \texttt{mark} (as integer)
    \end{itemize}
    \item Stores all student dictionaries in a list
    \item Displays the loaded data in a nicely formatted table
\end{enumerate}

\subsubsection*{Part 2: Data Analysis (60 marks)}

Extend your program to perform the following analyses:

\begin{enumerate}
    \item Calculate and display the average mark for all students
    \item Find and display the highest mark and the student who achieved it
    \item Find and display the lowest mark and the student who achieved it
    \item Count and display how many students passed (mark $\geq$ 50) and failed (mark $<$ 50)
    \item Calculate the average mark for each course separately
    \item Create a list of students who scored above 85 (distinction)
    \item Count how many students are in each course
\end{enumerate}

\subsection*{Requirements}

Your program must demonstrate:

\begin{itemize}
    \item Proper file handling with error checking
    \item Use of appropriate data structures (lists and dictionaries)
    \item Proper use of loops (for/while) for iteration
    \item Use of conditional statements (if/elif/else)
    \item Clear and organized output formatting
    \item Meaningful variable names and comments
\end{itemize}
